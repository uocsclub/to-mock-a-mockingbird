* A Curiosity

Another curiosity: show that any forest containing a robin and a kestrel must contain an identity bird.

** Answer

Let I = R𝛼K, for any 𝛼. Then, for all x, Ix = R𝛼Kx = Kx𝛼 = x.

* Some relatives

C*, a /cardinal once removed/ satisfies the following condition:

C*axyz = axzy

The bird C* is like C, except its action is 'deferred' until we skip over a; we then 'act' on the expression xyz as if we were using a cardinal.

And now see if you can derive C* from B and C.

** Answer

C*axyz = axzy = (ax)zy = C(ax) = C∘a = BC

* The bird R*

The bird R*—a /robin once removed/—bears much the same relation to R as C* does to C.

R*axyz = ayzx

Show that R* is derivable from B and C—and hence from B and T.

** Answer

R*axyz = ayzx = C*ayxz = C*ayx = C*C*a = C*C*

Interesting note: recall that R = CC. Is it always true that if αβ = γ, then α*β* = γ* for any birds α, β, γ?

* The bird F*

F*axyz = azyx

Now derive F* from birds derivable from B and C.

** Answer

F*axyz = azyx = R*axzy = C*(R*a)xyz = BC*R*

(Recall that F = BCR)

* The bird V*

Finally, we have the /vireo once removed/:

V*axyz = azxy

Show how to derive V* from birds derivable from B and C.

** Answer

V*axyz = azxy = F*ayxz = C*F*

* Twice Removed

Given birds B and C, find birds C**, R**, F**, V** such that for any birds a, b, x, y, z, the following conditions hold:

C**abxyz = abxzy
R**abxyz = abyzx
F**abxyz = abzyx
V**abxyz = abzxy

These are the birds C, R, F, V /twice/ removed. They will occasionally be useful.

** Answer

C**abxyz = abxzy = (C*a)bxyz = BC*
similarly, R** = BR*, F** = BF*, V** = BV*!

Does this trick work for deriving once-removed birds?

* Starring lemmas

The notation α[βxyz] means to "splice" in the output of β to α. For example, α[Cxyz] = αxzy, since the C swapped y and z.

** When is (AB)* = A*B*?

If A = α*, then (AB)* = A*B*.

Proof:

We want to show that A*B*a[args] = (AB)*a[args], = a[AB[args]].

A*B*a[args] = α**B*a[args] = B*a[αargs] a[B[αargs]] = a[α*B[args]] = a[AB[args]]

** When is A* = BA?

If A = α*, then BA = A*.

Proof:

We want to show that BAa[args] = A*a[args], = a[A[args]].

BAa[args] = Bα*a(firstarg)[restargs] = α*(a(firstarg))[restargs] = a(firstarg)α[restargs] = aα*(firstarg)[restargs] = a[A[args]]
