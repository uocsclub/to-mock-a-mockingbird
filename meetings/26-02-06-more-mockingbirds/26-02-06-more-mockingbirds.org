* Egocentric?

A bird x is called /egocentric/ if it is fond of itself. In symbols, x is egocentric if xx = x.

Prove, under the two conditions of the last problem, that at least one bird is egocentric.

** Answer

Since every bird is fond of a bird, in particular, the mockingbird is fond of a bird B. So MB = B. But MB = BB. So B = BB.

* Story of the Agreeable Bird

A and B are said to /agree/ on a bird x if Ax = Bx. A bird A is called /agreeable/ if for every bird B, there is at least one bird x on which A and B agree.

We are given the composition condition, but we are not given that there is a mockingbird; instead, we are given that there is an agreeable bird A. Is this enough to guarantee that every bird is fond of at least one bird?

** Answer

Take any bird B. There is a bird C that composes B and A. In other words, for all x, Cx = B(Ax). Now, since A is agreeable, there exists a bird z where Cz = Az. Now, Cz = B(Az). So, B(Az) = Az, and B is fond of Az.

** Bonus question

Why was the first question no more than a special case of this one?

** Bonus question answer

A mockingbird is agreable! For every bird B, MB = BB, so M and B agree on B. If we apply the logic from this question, let's take any bird A. There exists a bird B that composes A and M; Bx = A(Mx) for all x. Since M is agreeable, it agree with B on a bird, namely B itself. So MB = BB = A(MB), the exact same solution as before!

* A Question on Agreeable Birds

Suppose that the composition condition of Problem 1 holds and that A, B, and C are birds such that C composes A with B. Prove that if C is agreeable then A is also agreeable.

** Answer

Suppose that C is agreeable. Take any bird D. So there exists a bird E that composes D with B (in the future, I'm going to write composition birds E like D∘B to reduce the amount of letters I use). There exists a bird x on which C and E agree. So Cx = Ex. But Cx = A(Bx) and Dx = D(Bx). So A and D agree on Bx, and A is agreeable.
