* A dozen larks walk into a bar

Now let me tell you the most surprising thing I know about larks: Suppose we are given that the forest contains a lark L and we are not given any other information. From just this one fact alone, it can be proved that at least one bird in the forest must be egocentric!

Hint: construct an egocentric bird using just the letter L and parentheses

(Additional hints will be provided upon request)

** Answer

Consider the bird LL. We know that in a forest containing a lark, every bird is normal. So LL is fond of some x, that is, (LL)x = x.

LLx = x, L(xx) = x, L(xx)y = xy for all y, (xx)(yy) = xy

In particular, taking x = y, we get (xx)(xx) = xx.

So xx is egocentric! And we know that A is fond of (LA)(LA), so x = (L(LL))(L(LL)). Thus xx = ((L(LL))(L(LL)))((L(LL))(L(LL))) is egocentric.

* Is there a sage bird?

A sage bird Θ: if you call out x to Θ, Θ responds with a bird of which x is fond.

In other words, x(Θx) = Θx

Reminder: By the composition condition, for any bird x, there is /some/ bird y that composes x with the mockingbird M. Then, x is fond of the bird yy.
y = x∘M
yy = (x∘M)(x∘M) = x(M(x∘M)) = x((x∘M)(x∘M)) = x(yy)

Composition condition: for any two birds A and B, there exists a bird C that composes A and B. So Cx = A(Bx) for all x.

We have the mockingbird condition, the composition condition, and additionally, there is a bird A where if you call out x to A, A responds by naming a bird that composes x with M, ie, Axz = x(Mz) ∀x, z

** Solution

Consider Ax = x∘M. Thus Axy = (x∘M)(y) = x(My) = x(yy). So A is just the lark L!

We know that any bird B is fond of (LB)(LB) = M(LB), so let Θ = M∘L by the composition condition. This means that when you call out x to Θ, it will respond with M(Lx), of which x is fond.

* Bluebirds and Mockingbirds

Suppose that a bird forest contains a bluebird B and a mockingbird M. Since B is present, the composition law holds. Therefore, as you know, it follows that every bird x is fond of some bird. However, since B is present, you can write down an expression in terms of B, M, and x that describes a bird of which x is fond. Can you see how to write down such an expression?

Reminder: x is fond of M(x∘M)

** Answer

let f = M(BxM)
= (BxM)(BxM)
= x(M(BxM))
= x((BxM)(BxM))
= x f
so x is fond of f.

* Egocentric

Given a bluebird B [Bxyz = x(yz)] and a mockingbird M [Mx = xx], can you see how to write down an expression for an egocentric bird?

** Answer

Book's answer: M is fond of some x, namely, M(BMM). We've seen before that if M is fond of x, x is egocentric. So M(BMM) is egocentric.

My answer:

Consider the bird BM. BM is fond of an x, so (BM)x = x. (BM)xy = xy, M(xy) = xy, (xy)(xy) = xy, xy is egocentric.

We can actually write x (from the last problem) as M(B(BM)M). So for all y, M(B(BM)M)y is egocentric.
